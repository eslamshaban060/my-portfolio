# 🚀 Eslam Shaban – Portfolio

This is my personal portfolio website built using modern web technologies.

It serves as a professional digital identity where I showcase my skills, selected projects, and frontend engineering standards.

## 🛠 Tech Stack

- **Next.js (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **Framer Motion**
- Dark / Light Mode System
- Responsive Design (Mobile-First)
- Performance Optimization
- SEO Best Practices
